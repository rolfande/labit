Tilgang (GitHub-token)

Lag en fine-grained personal access token på GitHub (Settings → Developer settings → Personal access tokens → Fine-grained tokens), begrenset til dette repoet med tillatelsen Contents: Read and write. Tokenet lagres kun i denne nettleseren (localStorage) og sendes direkte til api.github.com — aldri til noe annet sted. Sett en kort utløpsdato og fjern/regenerer tokenet om du mistenker det er kompromittert.
